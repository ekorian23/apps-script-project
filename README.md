# Google Apps Script – IT Operations & Automation Projects

This repository contains a collection of Google Apps Script projects developed 
to support IT Operations, internal automation, and asset & package management workflows.

Each project focuses on reducing manual effort, improving operational visibility, 
and providing reliable internal systems using Google Sheets and web-based interfaces.

---

## 📂 Projects Overview

### 📦 Paket RG Jogja – Package Management System
Internal package management system for receiving, delivering, and monitoring 
employee packages at HQ Jogja, including dashboard, SLA monitoring, and documentation.

🔗 View project:  
[Paket RG Jogja](./Paket-RG-Jogja)

---

### 👥 View Employee Paket RG Jogja – Package Status Viewer
Read-only web module that allows employees to view their package status, 
highlight pending packages, and reduce manual inquiries to IT and Security.

🔗 View project:  
[View Employee Paket RG Jogja](./View-Employee-Paket-RG-Jogja)

---

### 📊 Stock Opname – Employee Asset Self Reporting
Annual self-reporting system that allows employees to submit asset details 
(serial number, MAC address, asset code) through a web form.

🔗 View project:  
[Stock Opname](./Stock%20Opname)

---

### 🔄 Mutasi IT to Snipe-IT – Asset & User Synchronization
Automation scripts for synchronizing users and assets from Google Sheets 
to Snipe-IT via REST API, supporting asset mutation and user onboarding.

🔗 View project:  
[Mutasi IT to Snipe-IT](./Mutasi%20IT%20to%20snipeit)

---

## 🧠 Tech Stack
- Google Apps Script
- Google Sheets

- REST API (Snipe-IT)
